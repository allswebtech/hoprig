# Every code span and code block of docs/HANDS-OFF.md, one row each, read by test/hands-off-examples.test.mjs.
#
# A row is:  verdict | context | text
#   verdict  held      the page says the wall holds this command line (wallHeld answers a hold)
#            not held  the page says it goes through (wallHeld answers null)
#            word      the page shows a name, a setting, an option or a part of a line, not a whole command a
#                      session would run; it is not asked of the wall
#            , unsaid  after held or not held: the page only names the command and says no verdict for it; the
#                      wall is still asked. Every other asked row's verdict is read from the page's own words too:
#                      the first "held" or "go(es) through" after the example, in its sentence.
#   context  plain     a repository whose default branch is main, the session on its branch feature
#            nodefault the same with no origin/HEAD: the default branch is not known
#            -         for a word
#   text     the span as the page shows it (its line breaks taken as one space); a code block is one row in which
#            each line break is written as the two characters \n
# Lines that begin with # and empty lines are not rows.
