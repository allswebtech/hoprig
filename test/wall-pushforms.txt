# Command lines beside the push and program forms the wall reads, one per row, read by test/wall-pushforms.test.mjs.
#
# A row is:  verdict | branch | text
#   verdict  held <reason id>  wallHeld holds the line with this reason id (WALL_REASON in src/wall.mjs)
#            not held          wallHeld lets it through: an everyday line that must keep going through
#   branch   the branch the session stands on (feature or main), in a repository whose default branch is main
#   text     the command line, as a coding tool would hand it to its shell
# The session stands in its own folder /w/shop. Lines that begin with # and empty lines are not rows.
