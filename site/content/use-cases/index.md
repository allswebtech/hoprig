# Use cases

Each page answers one question that people ask, in plain words: who it is for, what Hoprig does step by step (what you press in the dashboard first, then the command for a terminal), what you need, and what it does not do.

## What you get

- [Can the AI write the code for me?](/use-cases/review-ai-changes/#what-hoprig-does): Yes, in a chat: you say what you want in plain words, and you see each change and allow it before it is made.
- [How do I keep an AI-built project in order from day one?](/use-cases/messy-ai-project/#what-hoprig-does): Every project gets the same folder from the first day: the rules for the AI, its memory, the docs and the code, all in git.
- [Who sets up my computer for coding with AI?](/use-cases/not-a-developer/#what-hoprig-does): Hoprig does: one line installs it, and its setup installs and checks what is missing, after asking you once.
- [Can I code on several computers?](/use-cases/team-machines/#what-hoprig-does): Yes: each computer set up the same way from one recipe, and all of them on one page of the dashboard.
- [Can I code on my own computer from my phone?](/use-cases/code-from-your-phone/#what-hoprig-does): Yes: the dashboard opens in your phone's browser, with a chat per project and the real terminal, and no server of anyone else's.
- [Can AI-built code be ready for real use?](/use-cases/production-ready/#what-hoprig-does): Hoprig adds working rules that make the coding tool prove its work, and suggests reviewed skills for security, performance and tests.
- [Does it come with skills and tools?](/use-cases/production-ready/#easy-safe-fast-and-ready-to-grow): Yes: skills that fit what your project is made of, each with a scan of its risky lines before you add it, and a skill that sets up a new project from your brief.
- [What happens when my project grows large?](/use-cases/messy-ai-project/#when-the-project-grows): It stays in order: each part has one place, every repository is in one map, and plans are kept in Work. The AI's work still needs your review.
- [Does the AI brain learn?](/use-cases/messy-ai-project/#your-ai-brain-and-what-it-learns): There is one memory per project and one main brain, in git. Once you turn it on, it drafts skills from work you corrected or kept, at most three a week, and installs none without you.
- [Is it easy, safe and fast?](/use-cases/production-ready/#easy-safe-fast-and-ready-to-grow): The set-up is done for you, the working rules keep secrets out of the code, and skills for security and speed are suggested. It does not measure load for you.
- [Can I move my work to another computer?](/use-cases/new-computer/#what-hoprig-does): Yes: your AI brain lists every repository, so another computer gets the same projects, rules and memory.
- [Does everything come back from git?](/use-cases/new-computer/#what-hoprig-does): Yes: install Hoprig, sign in to git, and your AI brain, its map and your projects come back where they were.
- [Do my computers stay in step?](/use-cases/two-computers-one-workspace/#what-hoprig-does): Yes: the same rules, skills and memory through git, every repository brought up to date, and every computer's sessions on one page.
- [Can I run an AI team under one assistant?](/use-cases/ai-team/#what-exists-today): In part, today: Tia takes a goal, and sessions with six roles (developer, tester, reviewer, researcher, writer, ops) do its tasks, each checked before it comes back to you.
- [Coming: one dashboard for a whole business?](/use-cases/ai-team/#coming): Coming, not built yet: roles beyond code such as sales, posts sent only after your approval, and one dashboard for a whole business.
