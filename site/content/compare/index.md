# Compare Hoprig with the other ways

Three honest comparisons, each with what the other does better. The facts about the other tools come from their own pages and repositories, checked on 17 Nov 2026; things change fast, so check them again before you decide.

- [Hoprig and Claude Code's own apps and Remote Control](/compare/claude-code-remote-control/): the official way, from the makers of Claude Code.
- [Hoprig and Happy](/compare/happy/): a free phone app and terminal wrapper for Claude Code and Codex.
- [Hoprig and the do-it-yourself way](/compare/tmux-ssh-vpn/): tmux, SSH, a VPN and a terminal app on the phone.

## What Hoprig puts together

Searching the tools people use for AI coding, we found none that does all three of these: it sets up the computer; it keeps one workspace that comes back from git on any computer, with an AI memory per project; and a session goes on with another provider or account when one reaches its limit. That is what Hoprig is for. "We did not find one" is not proof that none exists.

## Where Hoprig is weaker

- There is no phone app: the dashboard is a web page.
- Nothing runs with your computer switched off: there is no cloud.
- It runs on Windows, macOS and Linux. Windows is new: a real home Windows PC has seen less of it than a Linux computer has, and the newer parts (the chat, the editor, Work) were not tried by hand on a real Mac.
- It is new: few people use it yet, and the last checks of this version ran on stand-ins for the coding tools.
