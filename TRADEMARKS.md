# Trademark policy

"Hoprig" and the Hoprig logo are trademarks of Kevin Pareek. This page says how you may use them. It follows the
way well-known projects word theirs (Mozilla, the Rust Foundation, Elastic).

## The licence of the code is not a licence for the name

Hoprig's code is under the Apache License 2.0 ([LICENSE](LICENSE)). You may use, change and share the code as
that licence allows. The licence does not give you the right to use the name "Hoprig" or the logo (section 6 of
the Apache License says so too). The name tells people where a program comes from, and this policy keeps that
true.

## Fine without asking

- Saying in words, truthfully, that something works with Hoprig, is built on Hoprig, is a plug-in or a skill for
  Hoprig, or is a guide to Hoprig: "a skill for Hoprig", "built on Hoprig".
- Sharing an unmodified copy of Hoprig, from this repository or from the npm package, under the name Hoprig.
  Packaging it for an operating system or a package manager counts as unmodified when the changes are only the
  ones needed to install it there and you say what you changed.
- Writing about Hoprig in articles, videos, books, talks and reviews, and using the name in a link to this
  repository or to hoprig.com.
- Using the name for a fork that only exists to send changes back to this repository, while it is not offered
  to others as a product.

Whatever you do, do not make it look as if your product, service or project comes from Hoprig or is approved by
it, and do not put the name or the logo in a way that stands out more than your own name.

## Needs written permission first

- A changed version of Hoprig, a fork, or a hosted service under the name "Hoprig" or under a name easily taken for
  it (such as "Hoprig Pro", "Hop Rig" or "Hoprigx"). A fork is welcome under a name of its own: give it its own
  name and logo, and you may say in words that it is based on Hoprig and not connected with it.
- The name or the logo in the name of your product, company, service or domain.
- The logo on a product, a package, a website as decoration, or anything sold.
- Any wording that suggests your work is official, endorsed or the original.

## How to ask

Open an issue in the Hoprig repository on GitHub (https://github.com/allswebtech/hoprig/issues) and say what you
want to do with the name or the logo. Permission is given in writing in that issue. If you are not sure whether
your use needs permission, ask the same way.
